# Alexs-Caves
Alex's Caves — six otherworldly cave biomes for Minecraft. Click the link and the .jar downloads instantly — no pages, no waiting. Magnetic, Primordial, Toxic, Abyssal, Forlorn, and Candy caves. Dinosaurs, bosses, 350+ blocks, 43 mobs. Works with Forge, NeoForge, and Fabric on 1.20.1–1.21.1. Requires Citadel.
